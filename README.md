# Mansik-Santulan-Score

An application designed to assess and predict mental health scores based on user inputs, built for portfolio building and resume demonstration.

## 🚀 Features
- User-friendly interface to input daily habits or assessment parameters.
- Calculates and predicts a comprehensive mental health score using Python and Jupyter Notebook.

## 🛠️ Tech Stack
- **Python, Jupyter Notebook, HTML, CSS, JavaScript**

## 💻 How to Run Locally
1. Clone the repository:
   ```bash
   git clone [https://github.com/Pranjalsingh241/Mental-Health-Score.git](https://github.com/Pranjalsingh241/Mental-Health-Score.git)
   Install the required dependencies:
   pip install -r requirements.txt
   Run the main file
   python main.py
